# microSD 카드로 SUFUN 켜기 (USB 없이)

이 Surface Go 3는 USB-C 포트로 **충전만 되고 데이터가 안 됩니다** (USB 부팅 불가).
그리고 Surface의 펌웨어(UEFI)는 **microSD 카드에서 직접 부팅하지 못합니다.**

그래서 이렇게 나눕니다:

| 위치 | 들어가는 것 | 크기 |
|---|---|---|
| **microSD 카드** | SUFUN 라이브 시스템 전체 (ISO 내용) | 약 3 GB |
| **내부 저장장치** | 아주 작은 "부팅 단계": 부팅 메뉴(systemd-boot) + 커널 + initramfs | 약 150 MB |

전원을 켜면 펌웨어가 내부 저장장치에서 커널을 읽고, 커널이 microSD 카드(UUID 번호로 찾음)에서 SUFUN을 시작합니다.
**Windows는 그대로이고, 계속 기본으로 켜집니다.** SUFUN은 원할 때만 고르면 됩니다.

> 카드: 32 GB, Class 10 U1 (A1/A2 등급 없음)도 됩니다. 다만 나중에 SUFUN을 카드에 **설치**하면
> 작은 파일 쓰기가 느려 조금 답답할 수 있습니다. 설치할 때 속도를 재서 알려 줍니다 (아래 5번).

---

## 0. 준비물

- microSD 카드 (16 GB 이상, 32 GB 권장). **카드의 내용은 지워질 수 있으니 먼저 백업하세요.**
- Surface UEFI에서 **Secure Boot = None** (이미 해 두셨습니다).
- **BitLocker 복구 키** (장치 암호화가 켜져 있으면 꼭 필요): 휴대폰 등 다른 기기에서
  <https://aka.ms/myrecoverykey> → Microsoft 계정 로그인 → 이 Surface의 48자리 키를 **종이에 적어 두세요.**

## 1. SUFUN ISO 내려받기 (Surface에서)

GitHub의 **Releases → SUFUN x.y** 에서 받습니다.

- ISO가 한 파일이면 `sufun-x.y-x86_64.iso` 만 받으면 됩니다.
- 조각(`.part00`, `.part01`, ...)으로 나뉘어 있으면 모두 받은 뒤 `ISO-합치는-방법.txt` 대로 합칩니다.
- 같은 곳에서 **`sufun-sd-setup.ps1`** 도 받으세요 (이 준비 스크립트).

**C: 공간이 부족하면:** 카드를 먼저 넣고, ISO(또는 조각)를 **카드에 바로** 저장하세요.
조각을 합칠 때도 결과를 카드에 만들면 됩니다 (cmd에서, `E:`가 카드일 때):
```
copy /b sufun-1.0-x86_64.iso.part00 + sufun-1.0-x86_64.iso.part01 E:\sufun-1.0-x86_64.iso
```
그다음 조각 파일은 지워도 됩니다.

## 2. 카드 넣기

microSD 카드를 Surface 뒷면 받침대(킥스탠드) 아래 슬롯에 끝까지 넣습니다.
파일 탐색기에 카드가 보이면 됩니다.

## 3. 준비 스크립트 실행 (한 번만)

1. 시작 단추를 **오른쪽 클릭 → "터미널(관리자)"** (또는 "Windows PowerShell(관리자)").
2. `sufun-sd-setup.ps1` 이 있는 폴더로 갑니다. 예: 다운로드 폴더라면
   ```powershell
   cd $HOME\Downloads
   ```
3. 실행합니다:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\sufun-sd-setup.ps1
   ```
4. 화면의 한국어 안내를 따라갑니다:
   - **Secure Boot 확인** → 꺼져 있어야 합니다.
   - **BitLocker 확인** → 켜져 있으면 복구 키를 준비했는지 묻고(`YES`), 다음 재시작 1번 동안
     BitLocker를 일시 중지할지 묻습니다 (**Y 권장**, 자동으로 다시 켜짐).
   - **ISO 경로** → 파일 탐색기에서 ISO를 **Shift + 오른쪽 클릭 → "경로로 복사"** 후 붙여넣기.
   - **카드 확인** → 카드 번호, 크기, 이름을 보여 줍니다. 맞으면 `YES` 를 입력합니다.
     스크립트는 **SD/MMC 또는 이동식 디스크만** 카드로 씁니다. Windows가 있는 디스크는 절대 안 씁니다.

스크립트가 알아서 두 경우를 구분합니다:

| 경우 | 무엇을 하나 | 나중에 "SD카드에 설치" |
|---|---|---|
| **(a) ISO가 내부 저장장치(C: 등)에 있음** | 카드를 포맷. 앞부분 약 4 GB에 라이브 파일, **나머지는 비워 둠** | ✅ 가능 |
| **(b) ISO가 카드에 있음** | 포맷하지 않음. 같은 카드에 ISO 내용을 풀고, ISO 파일을 지울지 물음 | ❌ 불가 (카드가 한 파티션) |

> **(b)로 만든 카드**는 라이브 실행과 "내부 저장장치에 설치"는 되지만, "SD카드에 설치"는 할 수 없습니다.
> 나중에 C: 공간이 생기면 ISO를 C:로 옮기고 스크립트를 다시 실행하세요 (그러면 (a)로 다시 만듭니다).

내부 저장장치에는 이것만 바뀝니다:
- EFI 시스템 파티션에 `\EFI\SUFUN\` 폴더와 `\loader\` 폴더 (SUFUN 표시 파일 포함),
- **EFI 파티션이 작으면** 대신: C:를 1 GB 줄이고 FAT32 파티션 **SUFUNBOOT** 를 만듭니다
  (탐색기에는 드라이브 문자 없이 숨겨집니다),
- 펌웨어 부팅 항목 **"SUFUN (SD)"** 를 부팅 순서 **맨 끝**에 추가 (Windows Boot Manager가 계속 첫 번째).

## 4. SUFUN 켜기

카드를 꽂은 채로, 둘 중 하나:

- **Windows에서:** 설정 → 시스템 → 복구 → 고급 시작 **"지금 다시 시작"** → **장치 사용** → **SUFUN (SD)**
- **꺼진 상태에서:** **볼륨 위(+)** 를 누른 채 **전원** → Surface UEFI → **Boot configuration** →
  **SUFUN (SD)** 를 **왼쪽으로 밀기(swipe)** = 지금 한 번 그걸로 부팅

검은 부팅 메뉴가 나오면 **SUFUN Live (microSD)** 를 고릅니다 (4초 뒤 자동).
메뉴 글자는 영어입니다: 펌웨어 화면에는 한글 글꼴이 없어서입니다.

처음 켤 때 카드가 느리면 1~2분 걸릴 수 있습니다. 바탕 화면이 나오면 Wi-Fi를 연결하세요.

**다음에 그냥 켜면 Windows가 켜집니다.** 카드를 빼 두어도 Windows는 평소처럼 켜집니다.

## 5. (선택) SUFUN 설치

바탕 화면의 **SUFUN 설치** 를 열면 두 가지를 고를 수 있습니다:

1. **SD카드에 설치 (윈도우 유지)** — SUFUN이 카드의 빈 공간에 설치됩니다 (btrfs, 내부 설치와 같은 구조).
   - 내부 저장장치에서는 `\EFI\SUFUN\` 폴더와 SUFUN 부팅 메뉴 항목만 바뀝니다. Windows는 그대로.
   - 설치 전에 카드의 **4K 무작위 쓰기 속도**를 잽니다. 2 MB/s 보다 느리면 한국어로 경고하고
     **A2 등급 카드**를 권하지만, 원하면 계속 설치할 수 있습니다.
   - 라이브 파티션은 지우지 않습니다: 부팅 메뉴에 **SUFUN Live (microSD, rescue)** 로 남아 복구용으로 씁니다.
   - 커널이 업데이트되면 새 커널이 자동으로 내부 저장장치의 부팅 단계에 복사됩니다
     (pacman 훅 + mkinitcpio 훅, `/usr/lib/sufun/sync-boot-stage`).
   - 켜는 방법은 4번과 같습니다 (**SUFUN (SD)**). 부팅 메뉴의 기본이 **SUFUN (microSD)** 로 바뀝니다.
2. **내부 저장장치에 설치 (윈도우 삭제)** — Windows가 지워집니다. 먼저
   [windows-restore-ko.md](windows-restore-ko.md) 를 꼭 읽으세요.
   설치 프로그램이 **복원 드라이런**(Windows를 지우기 전에 "Windows Setup" 부팅 항목이 실제로
   보이고 켜지는지 시험)을 권합니다.

설치 프로그램은 지금 라이브 시스템이 실행 중인 장치를 절대 지우지 않고, 모든 대상을
모델 이름과 크기와 함께 보여 준 뒤 `YES` / `ERASE` 를 직접 입력해야 진행합니다.

## 6. 모두 되돌리기

관리자 터미널에서:
```powershell
powershell -ExecutionPolicy Bypass -File .\sufun-sd-setup.ps1 -Uninstall
```
- 펌웨어 부팅 항목 "SUFUN (SD)" 삭제
- EFI 파티션의 `\EFI\SUFUN\` 과 SUFUN이 만든 `\loader\` 삭제
- SUFUNBOOT 파티션이 있었다면 삭제하고 **C:를 원래 크기로** 되돌림

microSD 카드의 파일은 그대로 둡니다. 카드를 다른 용도로 쓰려면 파일 탐색기에서 카드를
오른쪽 클릭 → **포맷** (exFAT). (카드에 파티션이 2개면 "디스크 관리"에서 둘 다 지운 뒤 새로 만드세요.)

## 문제 해결

| 증상 | 해결 |
|---|---|
| "관리자 권한이 필요합니다" | 시작 단추 오른쪽 클릭 → **터미널(관리자)** 에서 실행 |
| "스크립트를 실행할 수 없습니다" | 명령 앞에 `powershell -ExecutionPolicy Bypass -File` 를 붙여 실행 (위 3번) |
| "microSD 카드를 찾을 수 없습니다" | 카드를 다시 끝까지 넣고, 탐색기에 보이는지 확인 |
| 다음 Windows 시작 때 **BitLocker 복구 키** 화면 | 적어 둔 48자리 키를 입력 (한 번만 물어봄) |
| 부팅 메뉴에 **SUFUN (SD)** 가 없음 | 스크립트를 다시 실행 (같은 항목을 다시 씀) |
| SUFUN Live가 "waiting for device" 에서 멈춤 | 카드가 꽂혀 있는지 확인. 카드를 다시 만들었다면 스크립트를 다시 실행 (카드 UUID가 바뀜) |
