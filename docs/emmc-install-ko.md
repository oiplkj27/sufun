# SUFUN을 내부 저장장치에 설치하기 (Windows 삭제) — 순서대로

이 Surface Go 3는 **USB-C로 데이터가 안 되고 USB로 부팅할 수 없습니다.** 그래서 Windows를 지우기 전에
"돌아올 길"과 "업데이트 받을 길"을 먼저 확인합니다. **위에서부터 순서대로** 하세요.

|---|---|---|---|
| 1 | Windows (Git Bash) | 서명 키 만들기, GitHub에 올리기, 공개 키 커밋 | [signing-key-ko.md](signing-key-ko.md) |
| 2 | GitHub | 시험판 `v1.0rc1` 만들고 승인 → 키가 든 ISO 받기 | [signing-key-ko.md](signing-key-ko.md) 2번 |
| 3 | Windows | Windows 11 ISO와 "Surface Go 3 드라이버" MSI를 미리 받아 두기 | [windows-restore-ko.md](windows-restore-ko.md) |
| 4 | Windows + Surface UEFI | **복원 리허설**: 진짜 Windows 설치 화면이 USB 없이 뜨는지 확인 → `-Uninstall`. C: 를 9 GB 줄일 수 없으면 (이 Surface에서는 보통 그렇습니다) **가벼운 리허설** `-Light` | [windows-restore-ko.md](windows-restore-ko.md) 0단계 |

| 8 | SUFUN 라이브 | **SUFUN 설치 → 내부 저장장치에 설치**, Windows 파일 가져오기 | 아래 "설치" |

## 설치 전 확인 (5번)

- **BitLocker(장치 암호화)를 끄세요:** *설정 → 개인 정보 및 보안 → 장치 암호화 → 끔*. "암호 해독 중"이 끝날 때까지 기다립니다.
  켜져 있으면 SUFUN 설치 프로그램이 Windows 파일을 읽지 못해 **Windows 파일 가져오기를 할 수 없습니다.**
- **OneDrive "온라인 전용" 파일**(구름 아이콘)은 이 PC에 내용이 없습니다. 가져오기에서 빠지지만 OneDrive 웹에는 그대로 있습니다.
  꼭 필요한 파일은 Windows에서 오른쪽 클릭 → **"이 장치에 항상 유지"** 를 해 두면 함께 가져옵니다.
- **microSD 카드의 빈 공간**이 가져올 파일보다 커야 합니다 (32 GB 카드라면 약 27 GB까지). 파일은 RAM에 두지 않습니다.
- 가장 중요한 파일은 가져오기와 별도로 **다른 곳에도 한 벌** 두세요 (OneDrive, 다른 PC).

## 설치 (8번): 화면에서 물어보는 것

1. **설치 방법** → "내부 저장장치에 설치 (윈도우 삭제)"
2. (ISO에 업데이트 키가 없으면 빨간 경고가 나옵니다. 그 ISO로는 설치하지 마세요.)
3. **Windows 복원 리허설을 해 보셨나요?** → 4번에서 본 대로 고릅니다. `-Uninstall` 때 답한 결과가 미리 골라져 있습니다.
   "성공"이 아니면 위험을 설명하고, 그래도 계속할지 묻습니다 (막지는 않습니다).
   **가벼운 리허설**(`-Light`)이 성공했어도 "성공했음"을 고릅니다: 부팅 경로가 확인된 것으로 봅니다
   (요약 화면에는 "성공 (가벼운 리허설: 부팅 경로 확인됨)" 으로 나옵니다).
4. **Windows 파일 가져오기**
   - Windows 사용자의 **바탕 화면, 문서, 사진, 다운로드, 동영상, 음악** 폴더 크기를 보여 줍니다.
   - "모두 가져오기" / "폴더를 골라서" / "가져오지 않음" 중에서 고릅니다.
   - 고른 파일을 **먼저 microSD 카드에 복사**합니다 (카드의 빈 공간에 임시 파티션 `SUFUNKEEP` 을 만듦).
     Windows 파티션은 **읽기 전용**으로만 엽니다.
   - 복사 결과(폴더마다 몇 개 복사됨, 빠진 것)를 보여 줍니다.
   - **가져오지 않는 것:** AppData, 시스템 폴더, 프로그램, 바로 가기(.lnk), `desktop.ini`, OneDrive 온라인 전용 파일.
5. 컴퓨터 이름, 사용자 이름, 암호
6. **마지막 요약 화면**

   ```
   Windows와 모든 파일이 지워집니다.
     • 백업 (Windows 파일 가져오기): 문서,사진 3.2GB 복사됨 (파일 1234개)
     • 복원 리허설: 성공
     • 업데이트 키: 있음
   ```

   내용이 맞으면 `ERASE` 를 입력합니다. **여기서부터 되돌릴 수 없습니다.**
7. 설치 (10~30분). 끝나면 카드에 복사해 둔 파일을 새 SUFUN의 **바탕화면, 문서, 사진…** 폴더로 옮기고,
   카드의 임시 파티션을 지웁니다. 홈 폴더에 `Windows 파일 가져오기 결과.txt` 가 남습니다.

> 설치가 중간에 멈추면 (예: Wi-Fi 끊김): 복사해 둔 Windows 파일은 **microSD 카드에 그대로** 있습니다.
> 설치 프로그램을 다시 실행하면 "전에 복사해 둔 Windows 파일이 있습니다" 라고 묻고 이어서 가져옵니다.

## 설치 후 (9번)

- **켜지는지:** 다시 시작하면 SUFUN이 바로 켜져야 합니다. 설치 프로그램이 펌웨어 부팅 항목 **SUFUN** 을 **맨 앞**에 두고,
  옛 항목(Windows Boot Manager, SUFUN (SD), 리허설의 Windows Setup)은 지웁니다.
  펌웨어가 부팅 항목을 잃어버려도 예비 파일 `\\EFI\\BOOT\\BOOTX64.EFI` 로 켜집니다.
  - 그래도 안 켜지면: **볼륨 위(+) + 전원** → Surface UEFI → **Boot configuration** → `SUFUN` (또는 `Internal Storage`)를 맨 위로 끌어 올리세요.
- **Surface UEFI 암호**를 설정하세요 (README의 "UEFI 암호").
- **microSD 카드**는 빼서 따로 보관하세요.
- **하드웨어 점검**을 한 번 더 실행해 보고서를 올려 주세요.

## 복구 부팅 항목 (SUFUN Live, rescue)

내부 저장장치 설치가 끝나면 부팅 메뉴의 **"SUFUN Live (microSD, rescue)"** 항목은 **꺼져 있습니다.**

- **왜:** 이 항목은 microSD 카드의 라이브 시스템을 켭니다. 이 Surface를 손에 넣은 사람이 **자기가 준비한 카드**로
  다른 시스템을 켜서 내 파일을 읽는 길이 될 수 있습니다.
- **켜는 법 (필요할 때만):** 앱 메뉴 → **복구 부팅 항목** → 켜기 → 관리자 암호.
  그다음 카드를 꽂고 다시 시작 → 부팅 메뉴에서 "SUFUN Live (microSD, rescue)" 를 고릅니다. 다 쓰면 다시 끄세요.
- **SUFUN이 아예 안 켜져서 켤 수 없을 때:** 이 경우를 대비하려면, 평소에 문제가 없을 때 한 번 켜 두는 수밖에 없습니다.
  (보안과 복구 사이의 선택입니다. 집에서만 쓰는 기기라면 켜 두어도 됩니다.)

### 라이브 시스템의 암호

- **SUFUN이 설치된 컴퓨터**에서 라이브를 켜면: 로그인 화면이 나오고 **설치된 SUFUN의 관리자 암호**를 물어봅니다.
  자동 로그인 없음, `sudo` 와 관리자 창도 그 암호가 필요합니다. 설치된 디스크는 읽기만 합니다.
- **SUFUN이 설치되지 않은 컴퓨터** (처음 설치할 때): 암호 없이 바로 바탕 화면. 자동 화면 잠금은 꺼져 있습니다
  (라이브 사용자는 암호가 없어서 잠금을 풀 수 없기 때문).

**이것이 막는 것:** 내 카드와 내 Surface를 함께 가져간 사람이 라이브로 켜서 파일을 읽는 것.
**막지 못하는 것:** 직접 만든 다른 카드로 켜는 것 (그래서 복구 항목이 기본으로 꺼져 있음), 기기를 열어 저장장치를 직접 읽는 것,
SD카드 설치에서 카드를 빼서 다른 컴퓨터로 읽는 것. 디스크 암호화를 쓰지 않기로 했기 때문에 이 한계는 남습니다
(자세한 내용: [security-audit.md](security-audit.md) PH-1).

## 하드웨어 점검 (7번, 9번)

앱 메뉴 → **SUFUN 하드웨어 점검**. 한 번 누르면:

1. 설명 창 → 확인
2. **입력 테스트** 창: 터치패드를 움직이고, 화면을 터치하고, 펜으로 누르고, 키보드 키를 누르세요. 된 것은 초록색이 됩니다. → "끝"
3. **덮개 테스트**: 안내대로 덮개를 닫고 10초 뒤에 열고 [확인] (건너뛸 수 있음)
4. 나머지는 자동 (1~2분): 커널과 linux-surface 버전, x86-64-v3 지원, 입력 장치, 태블릿 모드 스위치, 가속도계,
   카메라 (목록, IPU3 상태, 카메라마다 시험 사진 1장), 덮개·절전, Wi-Fi/Bluetooth, 배터리, 메모리/zram,
   시스템 모니터 센서, 펌웨어 부팅 항목
5. 결과: 홈 폴더의 `sufun-hwcheck-날짜-시간.zip` (안에 `report.txt` 와 카메라 사진). 이 파일을 올려 주세요.

**개인 정보:** Wi-Fi 이름·암호, 일련 번호, MAC 주소, 컴퓨터 이름, 사용자 이름은 보고서에 넣지 않습니다.
카메라 시험 사진에는 카메라 앞에 있는 것이 찍히니, 올리기 전에 한 번 열어 보세요.
